# 国家税务总局上海市电子税务局 增值税发票开具与配套软件管理操作方案

> 适用平台：国家税务总局上海市电子税务局（https://etax.shanghai.chinatax.gov.cn）
> 方案性质：**通用可执行版本**（输入参数未具体化，先列缺失字段；本方案覆盖全部参数取值组合，可按分支直接定位执行）
> 合规底线：仅限官方平台与官方渠道，不生成任何绕过实名认证、规避税务监管、破解软件或非法开票的内容

## 一、前置条件检查

| 检查项 | 检查方法（导航路径） | 通过标准 | 未通过处理 |
|---|---|---|---|
| 实名认证状态 | 登录后进入「我的信息 → 用户管理」查看办税员实名认证状态 | 法定代表人/财务负责人/办税员已完成实名认证 | 下载「电子税务局」APP 完成人脸识别实名认证，或到主管税务机关办税服务厅办理 |
| 税务登记状态 | 「我的信息 → 纳税人信息 → 登记信息」 | 登记状态为「正常」 | 非正常户需先补申报、缴清欠税及罚款，申请解除非正常 |
| 票种核定情况 | 「我要办税 → 发票使用 → 发票票种核定」 | **数电票无需票种核定、无需发票领用**；电子发票（税控）/纸质发票需已核定对应票种 | 数电票跳过本项；税控发票未核定的，在「发票票种核定」模块申请 |
| 可用开票额度 | 「我要办税 → 发票使用 → 发票额度」（数电票授信额度） | 可用额度 ≥ 本次开票金额 | 在电子税务局「发票额度调整」申请调整，或联系主管税务机关 |
| 操作系统兼容性 | 查看本机系统版本 | 数电票打印控件支持 **Windows 7 / Windows 10 / Windows 11**；发票助手 PC 版为免安装客户端；发票助手安卓版支持 Android | macOS 等系统无法安装打印控件，需改用 Windows 电脑或到办税服务厅 |
| 软件版本兼容性 | 官网「下载中心 → 软件下载 → 发票助手」查看最新版本号 | 安装/使用官方最新版本 | 旧版本可能存在数电票兼容问题，按第五章卸载旧版后安装最新版 |

### 纳税人类型分支

| 纳税人类型 | 开票资格 | 执行路径 |
|---|---|---|
| 企业 | 可直接开具数电票（专票/普票） | 直接按第三章执行 |
| 个体工商户 | 可直接开具数电票（专票/普票） | 直接按第三章执行 |
| 自然人 | 一般不得直接开具数电票 | 办理临时税务登记后按企业流程开具，或通过电子税务局「代开增值税发票」申请税务机关代开 |

## 二、二维码生成方案

### 2.1 二维码应用规范总表（《便捷开票二维码应用规范》）

| 规范项 | 要求 |
|---|---|
| 编码格式 | QR 码 |
| 纠错等级 | M 级 |
| 二维码尺寸 | 不小于 1.8 cm × 1.8 cm |
| 周围空白区域（静默区） | 至少 4 个模块宽度 |
| 加密要求 | 涉及纳税人信息时**必须加密**，采用**国密算法**，保障数据传输安全 |
| 生成平台 | 仅限国家税务总局上海市电子税务局（etax.shanghai.chinatax.gov.cn） |

### 2.2 基础信息二维码（购买方长期使用）

| 要素 | 内容 |
|---|---|
| 二维码类型 | **基础信息二维码**（长期有效型） |
| 包含字段 | 购买方名称、购买方纳税人识别号、地址电话、开户行及账号（开具专票时必填）、接收发票邮箱 |
| 生成步骤 | 1. 登录电子税务局 →「我要办税 → 发票使用 → 便捷开票二维码/发票助手」；2. 选择「基础信息二维码」；3. 填写/核对购买方企业信息；4. 生成二维码并保存为图片或打印 |
| 二维码有效期 | 二维码本身**长期有效**；购买方扫码填写信息后同步至销售方开票列表，该条信息**有效时限 48 小时** |
| 交付方式 | 微信/邮件发送图片、打印张贴（尺寸 ≥1.8cm×1.8cm，四周留白 ≥4 模块） |
| 购买方扫码后操作 | 使用微信、支付宝、个人所得税 APP 或电子税务局 APP 扫码 → 核对/补填抬头信息 → 提交 |
| 销售方同步与开票 | 进入「我要办税 → 发票使用 → 蓝字发票开具 → 立即开票」，在开票列表选择「扫码带入」→ 购买方信息自动填充 → 按第三章继续开票 |

### 2.3 交易信息二维码（单笔交易即时生成）

| 要素 | 内容 |
|---|---|
| 二维码类型 | **交易信息二维码**（即时生成型） |
| 包含字段 | 销售方名称、销售方税号 + 交易信息（货物或服务名称、数量、单价、金额、税率/征收率、税额、价税合计） |
| 生成步骤 | 1. 进入「立即开票」界面；2. 选择发票类型与形式；3. 填写交易信息；4. 点击「生成交易信息二维码」；5. 保存或直接展示给购买方 |
| 二维码有效期 | **24 小时**，超时需重新生成 |
| 交付方式 | 面对面展示、微信/邮件发送图片 |
| 购买方扫码后操作 | 使用微信、支付宝、个人所得税 APP 扫码 → 提交抬头信息（名称、税号、开户信息等） |
| 销售方同步与开票 | 购买方提交后，销售方在开票列表收到待开票信息 → 一键带入 → 核对交易信息 → 开具并交付 |

### 2.4 两类二维码对比

| 对比项 | 基础信息二维码 | 交易信息二维码 |
|---|---|---|
| 生成时机 | 购买方一次性生成，长期使用 | 每笔交易由销售方即时生成 |
| 有效期 | 长期有效；同步后信息 48 小时有效 | 24 小时 |
| 包含内容 | 仅购买方抬头信息 | 销售方信息 + 交易明细 |
| 适用场景 | 固定采购方、反复交易 | 单笔偶发交易、现场结算 |

## 三、电子税务局自助开具流程

固定导航路径：**我要办税 → 发票使用 → 蓝字发票开具 → 立即开票**

| 步骤 | 操作动作 | 预期结果 | 异常处理 |
|---|---|---|---|
| 1. 登录 | 浏览器访问 https://etax.shanghai.chinatax.gov.cn，选择「企业业务」，输入税号/账号密码，或「电子税务局 APP 扫码」/插入 CA 证书登录 | 进入电子税务局首页，右上角显示企业名称 | 密码错误/账号锁定：通过「忘记密码」找回或联系主管税务机关重置；扫码登录失败：见第六章「用户令牌无效」 |
| 2. 进入开票模块 | 「我要办税 → 发票使用 → 蓝字发票开具 → 立即开票」 | 进入开票信息填写页面 | 菜单缺失：检查实名认证状态与办税员权限（「用户管理 → 办税员权限」），或确认登录身份为开票主体本身 |
| 3. 选择发票类型与形式 | 发票类型：增值税专用发票 / 增值税普通发票；发票形式：数电票 / 电子发票（税控）/ 纸质发票 | 页面切换为对应票种开具界面 | 无数电票选项：确认纳税人类型与注册信息，自然人需代开；额度不足见第六章 |
| 4. 填写购买方信息 | **方式一（推荐）**：选择「扫码带入」，自动同步 48 小时内的扫码信息；**方式二**：手动录入购买方名称、税号，专票还必须填写地址电话、开户行及账号 | 购买方信息完整准确，系统自动校验税号规则 | 扫码带入无信息：确认二维码未过期（基础信息 48 小时/交易信息 24 小时）且网络正常；税号校验不通过：核对购买方税号，或让购买方重新扫码提交 |
| 5. 填写交易信息 | 逐行填写：项目名称（选择税收分类编码）、数量、单价、金额、税率/征收率、税额、价税合计；差额征税/折扣等按需选择 | 系统自动计算税额与价税合计，行数据校验通过 | 税率带出不符：核实商品/服务税收分类编码；合计不符：检查数量×单价与折扣行；差额征税需先备案 |
| 6. 确认信息 | 点击「预览」核对票面全部信息（购销双方、明细、税率、价税合计） | 票面预览无误 | 信息错误：返回修改；已开具信息错误见第六章「发票信息错误」 |
| 7. 发票开具 | 确认无误后点击「发票开具」，按提示完成短信/APP 验证（如开通） | 系统返回开具成功，生成数电票票号（20 位） | 开具失败报错：核对额度、网络、登录状态；额度不足见第六章 |
| 8. 选择交付方式 | 可选：**二维码交付**（生成票面二维码供购买方扫码下载）、**电子邮件交付**（填写购买方邮箱，可设置自动交付）、**PDF 下载**、**OFD 下载** | 交付状态显示「已交付」，购买方收到发票文件或二维码 | 邮件未收到：检查垃圾邮件箱，确认邮箱无误后在「发票查询」重新交付；PDF/OFD 下载失败：换浏览器或清理缓存后重试 |
| 9. 验证开票结果 | 「我要办税 → 发票使用 → 发票查询」按条件查询；核对票号、金额、税率、交付状态；可通过全国增值税发票查验平台验证真伪 | 查询结果与票面一致，状态「已开具」 | 查询不到：确认开具主体与登录主体一致；数电票通常即时可查 |

> 补充规则：
> - 数电票无需票种核定和发票领用，但每次开具前需在「发票额度」确认可用额度充足。
> - 数电票开具错误不能直接作废的（已开具未交付且购买方未抵扣用途确认的可红冲），按第六章「发票信息错误」处理。
> - 纸质发票仍需税控设备/发票领用，开具后需抄税；本方案重点为数电票流程。

## 四、软件安装程序

### 4.1 官方下载来源（唯一合规渠道）

| 项目 | 内容 |
|---|---|
| 下载路径 | 上海税务网站 → **纳税服务 → 下载中心 → 软件下载 → 发票助手** |
| 建议做法 | 核对文件名、版本号、发布日期，下载官方数字签名安装包；不使用任何第三方站点、网盘、破解版本 |

### 4.2 安装前通用检查

| 检查项 | 通过标准 | 未通过处理 |
|---|---|---|
| 操作系统版本 | 打印控件：Windows 7 / 10 / 11（32/64 位与安装包一致）；PC 版：免安装客户端；安卓版：Android 系统 | 系统不兼容：更换电脑或到办税服务厅办理 |
| 管理员权限 | 使用管理员账户或右键「以管理员身份运行」 | 权限不足：联系本单位 IT 管理员授权 |
| 旧版本残留 | 无历史版本/失败安装残留 | 先按第五章彻底卸载并清理残留后再安装 |
| 安全软件 | 安装过程中可暂时关闭第三方安全软件实时防护 | 仍失败：见第六章「安装失败」 |

### 4.3 发票助手 PC 版（免安装客户端）

| 步骤 | 操作动作 | 预期结果 | 异常处理 |
|---|---|---|---|
| 1 | 从官网下载中心下载发票助手 PC 版安装包/客户端包 | 下载完成，文件完整 | 下载中断：重新下载并核对文件大小 |
| 2 | 解压（如为压缩包），双击运行客户端；**免安装**，无需写入系统目录 | 客户端界面正常打开 | 无法运行：右键「以管理员身份运行」；被杀毒软件拦截：添加信任 |
| 3 | 功能定位：**仅支持生成企业信息二维码**（基础信息二维码） | 可填写企业信息并生成二维码 | 功能不符预期：确认 PC 版定位，如需扫码识别请使用安卓版 |
| 4 | 生成二维码后保存/打印（≥1.8cm×1.8cm，四周留白 ≥4 模块） | 二维码清晰可扫 | 扫不出：见第六章「二维码无效」 |

### 4.4 发票助手安卓版

| 步骤 | 操作动作 | 预期结果 | 异常处理 |
|---|---|---|---|
| 1 | 从官网下载中心获取安卓安装包（APK），或通过官方指引的渠道安装 | 下载完成 | 提示「禁止安装未知来源应用」：在系统设置中允许当前浏览器/文件管理器安装 |
| 2 | 点击安装 → 授予相机（扫码）、存储（保存二维码）权限 | 安装成功，桌面出现图标 | 解析包错误：重新下载完整 APK，核对系统版本 |
| 3 | 功能使用：**支持二维码生成与扫码识别**；可通过 **USB 与计算机开票系统同步**数据 | 生成/扫码功能正常，USB 连接电脑后可同步 | USB 连接无反应：更换数据线/USB 口，开启手机「USB 调试」或文件传输模式，重装电脑端驱动 |
| 4 | 扫码提交的抬头信息同步至销售方开票列表（48 小时内有效） | 电子税务局「立即开票」列表可见待开票信息 | 同步失败：确认扫码 APP 为微信/支付宝/个税 APP/电子税务局 APP，检查网络与有效期 |

### 4.5 数电票纳税人端打印控件

| 步骤 | 操作动作 | 预期结果 | 异常处理 |
|---|---|---|---|
| 1 | 从官网下载中心下载「数电票纳税人端打印控件」安装程序 | 下载完成 | 确认选择 Win7/Win10/Win11 对应版本与 32/64 位 |
| 2 | 右键安装图标 → **以管理员身份运行** | 弹出安装界面 | 报错「无法访问/拒绝访问」：确认管理员权限；UAC 弹窗点「是」 |
| 3 | 进入安装界面 → 点击「安装」，按提示完成（安装路径建议默认，**避免中文或特殊字符路径**） | 进度条正常推进 | 卡死/报错：见第六章「安装失败」 |
| 4 | 等待完成 → 点击「完成」 | 安装结束 | — |
| 5 | 验证安装：桌面图标已生成、任务栏出现「已启动」提示（或浏览器打印插件加载成功） | 图标与运行提示均在 | 无图标：检查是否安装到其他路径；无「已启动」提示：重启浏览器或电脑 |
| 6 | 打印测试：在电子税务局下载 OFD/PDF 发票后，选择「打印」测试输出 | 打印预览正常，版式不错位 | 打印乱码/无响应：确认控件为最新版；确认浏览器未禁用插件；重装控件 |

## 五、软件卸载程序

适用对象：发票助手 PC 版、发票助手安卓版（安卓系统内卸载）、数电票纳税人端打印控件。

### 5.1 标准卸载

| 步骤 | 操作动作 | 预期结果 | 异常处理 |
|---|---|---|---|
| 1 | 控制面板 → **程序和功能** | 打开已安装程序列表 | Win11 可通过「设置 → 应用 → 已安装的应用」 |
| 2 | 找到目标软件（如「数电票纳税人端打印控件」「发票助手」）→ 右键/双击 → **卸载** | 弹出卸载向导并正常执行 | 列表找不到：说明可能是免安装客户端，直接删除目录；或按 5.2 深度卸载 |
| 3 | 按向导提示完成卸载 | 程序从列表消失 | 卸载中断/报错：重启电脑后重试；仍失败按 5.2 |

### 5.2 深度卸载

| 步骤 | 操作动作 | 预期结果 | 异常处理 |
|---|---|---|---|
| 1 | 打开软件安装目录（默认如 `C:\Program Files\` 下对应目录） | 找到 `uninstall.exe` | 无 uninstall.exe：用 5.1 标准卸载或专业卸载工具 |
| 2 | 右键 `uninstall.exe` → **以管理员身份运行** | 卸载向导执行完毕 | 执行无效：按 5.3 清理残留 |
| 3 | 安卓版：在手机「设置 → 应用管理」中选择发票助手 → 卸载 | 应用移除 | 无法卸载（设备管理应用）：先撤销设备管理器权限 |

### 5.3 清理残留

| 清理对象 | 操作动作 | 预期结果 | 异常处理 |
|---|---|---|---|
| Program Files 目录 | 检查 `C:\Program Files\` 与 `C:\Program Files (x86)\` 下是否残留软件目录，确认无用时删除 | 无软件相关目录 | 删除被占用：重启电脑或进入安全模式删除 |
| 临时文件夹 | 按 `Win+R` 输入 `%temp%` 清理临时文件 | 临时文件清空 | 部分文件占用中：跳过即可 |
| 注册表项 | `Win+R` 输入 `regedit`，**先导出备份注册表**，再搜索关键词 **ITSKHD、Servyou** 等，删除相关项（仅删除确认属于该软件的项） | 搜索无相关残留项 | 不熟悉注册表：使用专业卸载工具自动清理；误删后导入备份恢复 |

### 5.4 安装冲突处理

| 处理方式 | 操作动作 | 适用场景 |
|---|---|---|
| 专业卸载工具 | 使用 Revo Uninstaller 等专业工具，卸载后扫描并清除残留文件和注册表项 | 反复安装失败、标准卸载报错 |
| 更换安装路径 | 重新安装时选择不含中文、空格及特殊字符的路径（如 `D:\TaxSoftware`） | 原路径含中文导致安装/打印异常 |
| 重新安装官方最新版 | 从官网下载中心重新下载最新安装包，按 4.2 检查后安装 | 清理完成后恢复正常使用 |

### 5.5 卸载完成验证

| 验证项 | 通过标准 |
|---|---|
| 进程 | 任务管理器中无该软件相关进程 |
| 服务 | `services.msc` 中无该软件相关服务 |
| 文件 | Program Files、临时文件夹无残留 |
| 注册表 | 搜索 ITSKHD、Servyou 等关键词无相关项 |
| 功能 | 浏览器打印发票不再调用该控件 |

## 六、异常处理

| 异常现象 | 可能原因 | 解决方案（按顺序执行） |
|---|---|---|
| **二维码无效** | 1. 二维码模糊、破损、尺寸过小或打印留白不足；2. 二维码过期（基础信息超 48 小时、交易信息超 24 小时）；3. 扫码 APP 不受支持；4. 网络不通 | 1. 核对清晰度与尺寸（≥1.8cm×1.8cm、四周留白 ≥4 模块）；2. 超时则让购买方重新生成或让销售方重新生成；3. 确认使用微信、支付宝、个人所得税 APP 或电子税务局 APP 扫码；4. 检查双方网络后重试 |
| **用户令牌无效** | 电子税务局 APP 版本过旧、登录态失效、账号在别处被顶下线 | 1. 将电子税务局 APP 更新至最新版本；2. 退出后重新登录；3. 重启 APP 与手机网络；4. 仍失败联系主管税务机关或 12366 |
| **人脸识别失败 / 人脸识别二维码无效** | 扫码 APP 用错、光线不佳、网络不稳、实名信息不符 | 1. 确认使用**电子税务局 APP 或个人所得税 APP**扫码（不要用浏览器扫）；2. 光线充足、正对摄像头；3. 切换网络重试；4. 多次失败转办税服务厅实名认证 |
| **安装失败** | 权限不足、系统不兼容、安全软件拦截、旧版本残留、安装路径含中文/特殊字符 | 1. 右键「以管理员身份运行」；2. 使用兼容性模式（右键属性 → 兼容性 → 按需选 Win7 模式）；3. 暂时关闭安全软件后重试；4. 按第五章彻底清理旧版残留；5. 更换为英文/数字路径；6. 重新下载官方最新安装包 |
| **卸载残留** | 标准卸载不完整、安装目录残留、注册表项残留 | 1. 使用安装目录下 `uninstall.exe` 深度卸载；2. 清理 Program Files、%temp% 临时文件夹；3. 备份后清理注册表（ITSKHD、Servyou 等关键词）；4. 使用 Revo Uninstaller 等专业工具；5. 按 5.5 验证卸载完成 |
| **开票额度不足** | 数电票可用额度低于开票金额、额度未生效、当月额度已用尽 | 1. 「我要办税 → 发票使用 → 发票额度」查看明细；2. 在电子税务局「发票额度调整」申请调整；3. 联系主管税务机关核实；4. 额度恢复后再开具 |
| **发票信息错误** | 购买方信息、明细、税率、金额填错 | 1. 数电票：通过「我要办税 → 发票使用 → 红字发票开具」发起红冲，注明错误原因，待对方确认（如对方已抵扣用途确认需其确认）；2. 税控电子/纸质发票：当月未抄税可作废，跨月需红冲；3. 红冲/作废成功后重新开具正确发票并交付 |
| **其他（开具报错、无法打印、无法交付）** | 登录态失效、浏览器兼容性、控件未装、额度/网络问题 | 1. 重新登录或更换浏览器（推荐 Chrome/Edge 最新版）；2. 确认打印控件已按第四章安装并「已启动」；3. 确认额度与网络；4. 截图报错信息联系主管税务机关或拨打 12366 |

## 七、合规与安全提示

| # | 提示 |
|---|---|
| 1 | 所有操作必须符合国家税务总局和上海市税务局最新政策；政策更新时**以官网最新公告为准** |
| 2 | 纳税人信息在二维码生成、传输、扫码全流程**必须加密**，采用国密算法，保障数据传输安全 |
| 3 | 二维码仅用于合规便捷开票，**不得用于非法开票**、不得买卖发票、不得虚开 |
| 4 | 发票助手、数电票打印控件等软件**必须从官方渠道下载**（上海税务网站 → 纳税服务 → 下载中心 → 软件下载 → 发票助手），严禁使用破解、篡改版本 |
| 5 | 不得通过任何技术手段绕过实名认证、人脸识别或税务监管 |
| 6 | 开票数据（购销双方、明细、税额）必须真实反映交易实际，红冲/作废须如实填写原因 |
| 7 | 注册表清理等高风险操作前务必备份；不熟悉时联系本单位 IT 人员或主管税务机关 |
| 8 | 平台地址仅限 https://etax.shanghai.chinatax.gov.cn，谨防仿冒钓鱼网站 |
